03服务内容

3.1 服务性质

本应用是一款面向南京理工大学在校学生的本地工具类应用。除云备份与你主动授权的第三方登录外， 数据处理与展示均在你的设备上完成；我们不提供在线存储课表、成绩或用户内容的服务。

3.2 功能范围

本应用可能提供以下功能，具体以你所使用版本的实际界面为准：

  1. 课表：课表展示、周次切换、午休与晚休格子、课表背景、课程配色与主题、课表整屏查看、下拉刷新；
  2. 成绩与考试：成绩查询、学分与绩点统计、成绩明细、成绩模拟、考试安排、学期报告；
  3. 教务查询：选课情况汇总、空闲教室、教室课表、教师课表、课程查询、课程大纲；
  4. 图书馆：馆藏检索、研修小间（研讨室）预约、预约撤销与签退；
  5. 校园服务：失物招领浏览与发布、师生服务平台咨询浏览与提问、常用链接、校园地图与校历；
  6. 课表协作：文本码互传、蓝牙直传、课表图片分享、同学课表叠加、共同空闲时间计算；
  7. 导出与备份：导出到日历（.ics）、课表打印导出、加密备份导出与恢复、WebDAV 备份、GitHub 备份、百度网盘备份；
  8. 提醒与小组件：考试与成绩提醒、课程状态通知、桌面小组件、后台定期检查（仅 Android）；
  9. 其他：WebVPN 入口、网络诊断、诊断日志、版本检查与更新。

3.3 平台与账号差异

  1. 部分功能仅在特定平台提供：云端备份仅 Android / iOS 提供；后台定期检查仅 Android 提供；网页版受浏览器同源策略限制，需经代理访问学校系统，部分依赖学校门户的功能在网页版会跳转至学校官方页面；
  2. 部分功能仅对本科生账号或研究生账号开放，具体以界面是否显示为准；
  3. 本应用可能通过远端配置开关控制个别功能的可见性（例如审核期间暂时隐藏某个功能）。开关不影响你已产生的本地数据。

3.4 服务的免费性质

  1. 本应用免费提供，不含内购、订阅、付费解锁或会员体系；
  2. 你使用本应用产生的网络流量费用由你与你的运营商结算；
  3. 若未来引入收费功能，我们会提前公示价格、服务内容与退订方式，并由你主动选择是否购买；
  4. 本应用内可能展示第三方平台（如百度网盘）的官方活动入口。该入口为普通外部链接，本应用不参与该活动的交易与结算，不代收款项，不获取你的订单与支付信息。

3.5 非官方声明

本应用不是学校官方产品，未获得学校授权、认可或背书。你不得以本应用的名义对外代表学校，也不得把本应用的输出内容作为学校官方文件使用。

04账号与凭据

4.1 学校账号

  1. 本应用不建立注册账号体系，你使用学校统一身份认证账号登录；
  2. 学校账号的开通、权限、密码找回与注销由学校管理，我们无权代办；
  3. 你应确保使用的是本人账号，不得使用他人账号登录，不得将账号借予他人使用；
  4. 因学校统一认证策略调整、单点登录限制、验证码机制变化导致登录失败或功能受限的，不视为我们违约。

4.2 图书馆系统账号

研修小间预约使用校园卡号与图书馆系统独立密码（初始密码可能为空），与学校统一身份认证密码不同。 你应自行保管该密码，并按图书馆规则使用预约功能，包括每日预约次数、可预约天数、单次时长与撤销规则。 撤销预约不退还当日预约次数等业务规则由图书馆系统决定。

4.3 凭据保管

  1. 为支持免重复登录，本应用会在本机保存你的账号与密码（密码为混淆形式）。混淆不等于加密，在已 root / 越狱或被他人物理接触的设备上存在被还原的风险；
  2. 你应妥善保管设备与账号，设置锁屏密码，避免在公用设备上保存凭据；
  3. 因你自行泄露、出借账号、在不安全环境使用或操作不当造成的后果，由你自行承担。

4.4 第三方平台授权

  1. 云备份需要你主动完成第三方平台授权。授权在你的浏览器中由第三方平台完成，本应用不接触第三方平台的账号密码；
  2. 授权后产生的访问令牌保存在本机。你可以在应用内「断开连接」，或在第三方平台的授权管理中撤销授权；
  3. 你应确保用于备份的百度网盘账号、GitHub 账号与 WebDAV 账号为你本人所有或你有权使用。

6.2 百度网盘相关约定

本节适用于你使用「百度网盘备份」功能的情形：

  1. 授权范围：本应用仅在百度网盘开放平台授权的 basic、netdisk 权限范围内，代表你访问你本人的网盘，并且仅读写应用专属目录 /apps/{应用名}；
  2. 不作他用：本应用不会读取、遍历、下载、分析你网盘中的其他文件，不会把你的网盘数据提供给任何第三方，也不会用于广告、画像或其他商业目的；
  3. 上传内容：你应确保上传的备份文件仅包含你自己的数据。备份内容可能包含你的课程信息、备注与课表背景图，请勿上传他人的个人信息，也请勿上传含身份证件、住址等不必要敏感信息的图片；
  4. 加密与口令：我们建议你为每次备份设置口令。备份口令由你设定，我们不保存、不上传、无法找回。未设置口令的备份未加密，任何取得该文件或能登录该网盘账号的人均可读取其内容；
  5. 背景图：课表背景图作为单独文件上传，不加密封装。请勿使用含个人信息的图片作为课表背景；
  6. 删除：本应用不提供删除云端文件的能力。你应在百度网盘客户端或网页中自行删除；删除后不可恢复；
  7. 授权撤销：你可以在百度网盘「设置 → 授权管理」中撤销对本应用的授权，或在应用内「断开连接」。撤销后本应用无法再访问你的网盘；
  8. 关系说明：本应用不是百度网盘官方产品，不由百度提供担保。百度对你网盘账号内数据的处理适用百度自身的协议与政策；

08备份、恢复与数据丢失

8.1 备份的性质

  1. 备份是辅助手段，不是数据安全的唯一保障。我们建议你同时保留本地导出文件，并对重要内容做多重备份；
  2. 备份内容限于本机保存的、重装后难以重建的数据（如自定义课程、备注、调课、背景图、设置）。教务课表、成绩与考试可由学校系统重新拉取，不进入备份；
  3. 备份文件使用 AES-256-GCM 加密，密钥由你的口令经 PBKDF2-HMAC-SHA256 派生。口令遗失即无法恢复，我们没有任何后门或找回手段。

8.2 恢复的风险

  1. 「覆盖本机数据」会用备份内容覆盖本机同名项，可能使你当前设备上的改动丢失，请谨慎选择；
  2. 「仅补齐缺失项」不会覆盖已有内容，但可能造成新旧数据混用；
  3. 恢复后部分内容需重启应用才能完全生效；
  4. 恢复前建议先导出当前数据作为回退点。

8.3 责任边界

  1. 因你遗忘口令、误删文件、在第三方平台清空目录、撤销授权、更换账号等原因导致备份不可用的，我们不承担责任；
  2. 因第三方平台服务中断、容量限制、接口变更、账号被封禁导致备份失败或丢失的，我们不承担赔偿责任，但会尽力提供排查建议；
