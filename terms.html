1.6　云备份　指本应用将您在终端设备本地生成的备份文件写入您所选定之第三方平台的辅助功能， 包括百度网盘备份、WebDAV 备份与 GitHub 备份。

第三条服务内容与使用许可

3.1　服务性质

本应用系面向南京理工大学在校学生提供的本地工具类应用。除云备份及您主动授权的第三方登录外， 本应用的数据处理与展示均于您的终端设备本地完成。我们不提供课表、成绩或用户内容的在线存储服务， 亦不因本服务向您收取任何费用。

3.2　功能范围

本应用可提供下列功能，具体以您所使用的版本及实际界面所呈现者为准：

  1. 课表：课表展示、周次切换、午休与晚休格子、课表背景、课程配色与主题、课表整屏查看、下拉刷新；
  2. 成绩与考试：成绩查询、学分与绩点统计、成绩明细、成绩模拟、考试安排、学期报告；
  3. 教务查询：选课情况汇总、空闲教室、教室课表、教师课表、课程查询、课程大纲；
  4. 图书馆：馆藏检索、研修小间（研讨室）预约、预约撤销与签退；
  5. 校园服务：失物招领浏览与发布、师生服务平台咨询浏览与提问、常用链接、校园地图与校历；
  6. 课表协作：文本码互传、蓝牙直传、课表图片分享、同学课表叠加、共同空闲时间计算；
  7. 导出与备份：导出至日历（.ics）、课表打印导出、加密备份的导出与恢复、WebDAV 备份、GitHub 备份、百度网盘备份；
  8. 提醒与小组件：考试与成绩提醒、课程状态通知、桌面小组件、后台定期检查（仅限 Android）；
  9. 其他：WebVPN 入口、网络诊断、诊断日志、版本检查与更新。

3.3　平台与账号差异

  1. 部分功能仅在特定平台提供：云备份功能仅由 Android 版与 iOS 版提供；后台定期检查仅由 Android 版提供。 网页版受浏览器同源策略限制，须经代理访问学校系统；依赖学校门户的部分功能于网页版将跳转至学校官方页面。
  2. 部分功能仅对本科生账号或研究生账号开放，具体以相应功能是否于界面中显示为准。
  3. 我们可通过远端配置对个别功能的可见性进行控制（例如于审核期间暂时隐藏特定功能）。前述控制不影响 您于本机已经产生的数据。

3.4　服务的无偿性

  1. 本服务无偿提供，不包含内购、订阅、付费解锁或会员体系。
  2. 您因使用本服务所产生的网络流量费用，由您与您的电信业务经营者另行结算。
  3. 如我们于将来引入收费项目，将事先公示其价格、服务内容与退订方式，并由您自主选择是否购买。
  4. 本应用内可能展示第三方平台（如百度网盘）官方活动的入口。该等入口仅为普通外部链接， 开发者不参与相应活动的交易与结算，不代收款项，亦不获取您的订单信息与支付信息。

3.5　非官方声明与标识使用

本应用并非学校官方产品，未获得学校的授权、认可或背书。您不得以本应用的名义对外代表学校， 亦不得将本应用的输出内容作为学校官方文件使用。「梨课程」名称与图标仅用于标识本应用， 未经我们事先书面同意，您不得于修改版、衍生品或宣传材料中使用相同或近似的标识， 致人误认其为官方版本。

第四条账号、凭据与第三方授权

4.1　学校账号

  1. 本应用不设注册账号体系，您以学校统一身份认证账号登录并访问学校系统。
  2. 学校账号的开通、权限配置、密码重置与注销，均由学校依其规则管理，我们无权代为办理。
  3. 您应当确保所使用之账号为您本人合法持有，不得以他人账号登录，不得将账号出借、转让 或与他人共用。
  4. 因学校统一认证策略调整、单点登录限制或验证码机制变更，致登录失败或部分功能受限的，不构成我们违约， 我们不因此承担违约责任。

4.2　图书馆系统账号

研修小间预约功能使用校园卡号及图书馆系统之独立密码（初始密码可能为空），与学校统一身份认证密码相互独立。 您应当自行保管该密码，并依图书馆发布之规则使用预约功能，包括每日预约次数、可预约天数、单次使用时长及撤销规则。 撤销预约不退还当日预约次数等业务规则，由图书馆系统单方决定，我们不参与其制定，亦无权变更。

4.3　凭据的本地保管

  1. 为免重复登录之目的，本应用将于您的终端设备本地保存账号与密码（密码以混淆形式存储）。 混淆不等同于加密，于已取得 root 或越狱权限的设备，或于被他人实际接触之设备上， 存在被还原之风险。您已知悉并自愿承担前述风险。
  2. 您应当妥善保管终端设备与账号凭据，设置锁屏密码，并避免于公共或共用设备上保存凭据。
  3. 因您自行泄露凭据、出借账号、于不安全环境中使用或操作不当所致之损失，由您自行承担。

4.4　第三方平台的授权

  1. 云备份功能的实现以您主动完成第三方平台授权为前提。授权于您的浏览器中由第三方平台完成， 本应用不接触、不收集第三方平台的账号与密码。
  2. 授权完成后所产生之访问令牌保存于您的终端设备本地。您可于本应用内选择「断开连接」， 亦可于第三方平台的授权管理页面中撤销授权。
  3. 您应当确保用于备份的百度网盘账号、GitHub 账号及 WebDAV 账号为您本人所有， 或您已取得合法使用权限。

6.2　百度网盘相关约定

本条适用于您使用「百度网盘备份」功能之情形：

  1. 授权范围　本应用仅在百度网盘开放平台所授予之 basic、netdisk 权限范围内，代表您访问您本人的网盘，且仅读写应用专属目录 /apps/{应用名}。

  3. 上传内容　您应当确保所上传之备份文件仅包含您本人的数据。备份内容可能包含课程信息、 备注及课表背景图片，请勿上传他人个人信息，亦请勿上传含有身份证件、住址等不必要敏感信息之图片。
