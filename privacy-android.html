隐私政策

适用产品：Android 客户端 适用版本：1.1.9 及以后 政策版本：v2.0 生效日期：2026 年 10 月 20 日

本政策仅适用于梨课程 Android 客户端 1.1.9 及以后版本，说明我们如何处理你的信息、使用哪些第三方服务， 以及你对自己信息享有的权利。

概要

登录后由设备直接连接学校系统获取数据，不经过开发者服务器；版本检查、公告、校历图片与安装包由 CDN 分发。

数据主要流向
你的设备 ↔ 南京理工大学相关系统（直连）；设备 ↔ CDN
第三方统计
Microsoft Clarity 使用情况记录，默认关闭，需你主动同意
本地存储
应用私有目录：学号、混淆后的密码、课表 / 成绩 / 考试缓存、设置、备注
跨境传输
仅当你开启数据收集时，使用情况数据传至 Microsoft（境外）
系统权限
网络、通知、读取图片（自定义背景）、安装应用（应用内更新）
账号体系
无注册、无开发者侧账号；使用学校统一身份认证账号

我们遵循最小必要原则：只处理实现你主动使用的功能所必需的信息。

教务数据：姓名、学号、学院专业、课表、成绩、考试安排、教师课表 是 设备本地缓存 否（由学校系统返回后存于本地）

关于密码的重要说明

为支持「下次启动免重复登录」，客户端会把你的密码保存在本机。密码以混淆形式写入存储， 目的是避免明文直接出现在文件中，但混淆不等于加密：在已 root 的设备上， 具备相应权限的第三方仍可能还原出密码。请勿在公用设备或已 root 的设备上记住密码。

我们不收集的信息

  • 我们不建立开发者侧的用户账号体系，不收集你的手机号、邮箱、身份证号、住址；
  • 我们不采集设备标识符，不读取通讯录、短信、通话记录、精确位置、摄像头或麦克风；
  • 我们不接入广告平台，不出售、不租借你的个人信息，不将信息用于广告定向；
  • 我们不接入第三方崩溃收集服务，应用崩溃不会自动上传。

03信息的来源与具体场景

3.1 你主动提供的信息

  • 登录凭据：你在登录页输入的学号与密码，以及选择的账号类型（本科生 / 研究生）。登录成功后保存在本机，用于下次自动登录。
  • 自定义内容：你添加的课程备注、自定义课程、课表背景图。这些内容仅保存在你的设备上，不会上传。
  • 反馈信息：当你加入 QQ 反馈群或在群内反馈问题时，你主动发送的文字、截图与联系方式由你自行提供，我们仅用于定位与回复问题。

3.2 从学校系统获取的信息

在你登录后，应用会以你的身份向学校系统请求并展示以下信息，并将其缓存到本地以便离线查看：

  • 姓名、学号、学院与专业等基本信息；
  • 本学期课表、课程名称、上课时间、地点、任课教师；
  • 考试成绩、学分与绩点、考试安排；
  • 你主动使用的其他校园服务查询结果（如教师课表、空闲教室、校园卡相关查询等）。

这些信息由学校系统生成与维护，我们只是展示工具，不对其准确性、完整性与及时性作出保证。

3.3 设备与日志信息

类型 说明
应用与系统信息 版本号、构建号、操作系统类型与版本、界面语言。用于版本检查、兼容性判断与问题定位，不上传。
网络请求记录 访问学校系统与 CDN 时产生的请求地址、时间与结果。正常使用时不保存；仅在排障日志开启后记录在本机。
诊断日志 默认关闭。开启后记录操作、HTTP 请求与响应、解析结果与错误，内容不做脱敏，可能包含账号、Cookie、课程与教师信息。仅存本机，最多保留 3 天、约 20 MB，超出自动删除。
统计信息 仅在你同意后由第三方统计服务采集，详见第 06 节。

3.4 网络连接与权限

Android 客户端直接连接学校系统（bkjw.njust.edu.cn、ids.njust.edu.cn、 ehall2.njust.edu.cn 等），你的登录请求不经过我们的服务器。 应用会申请网络、通知、读取图片与安装应用权限：通知用于考试 / 成绩提醒；读取图片仅在你选择课表背景时使用； 安装应用权限仅用于安装你确认下载的更新包。

04本地存储与会话凭据

客户端不使用 Cookie，而是通过操作系统的应用私有存储保存数据。所有本地存储都用于维持登录状态、 缓存数据与保存设置，不用于跨站追踪或广告投放。

技术 用途与内容
系统键值存储（SharedPreferences） 保存登录凭据、课表 / 成绩缓存、设置与备注。数据位于应用私有目录，其他应用无法直接读取。
会话 Cookie 与学校系统通信时在内存或本地保存会话 Cookie，用于维持登录。退出登录会清除凭据与会话 Cookie。
统计标识 仅在你同意数据收集后，由 Microsoft Clarity 设置用于区分独立访客的标识；关闭数据收集后不再产生新的统计请求。

如何管理

  • 在「设置 → 数据收集与隐私政策」关闭数据收集；
  • 在「设置 → 存储空间」清理缓存与诊断日志；
  • 退出登录可删除保存的学号、密码、账号类型与会话 Cookie。

06第三方统计与 SDK

默认关闭，需你主动同意

使用统计为选择性加入。首次启动时，「参加用户体验改进计划」复选框默认不勾选； 不勾选不影响任何功能。你可以在「设置 → 数据收集与隐私政策」随时更改。

Microsoft Clarity

仅当你开启数据收集后，客户端才初始化 Microsoft Clarity。 它用于使用情况记录与交互分析，帮助我们定位界面问题、改进操作流程。

  • 可能记录：你与应用界面的交互（点击、滚动、页面切换）、设备型号与操作系统版本、屏幕尺寸、语言、IP 地址及由此推断的粗略地理位置、应用版本。
  • 使用范围：上述记录仅用于改进产品与使用体验，不用于广告投放、用户画像或跨应用追踪。
  • 关闭方式：设置 → 数据收集与隐私政策 → 关闭「允许数据收集」，关闭后停止采集。撤回同意不影响撤回前已进行的处理。
  • 隐私声明：Clarity 数据隐私说明、 Microsoft 隐私声明。

我们未使用的第三方服务

  • 无广告 SDK、无推送 SDK（提醒由系统本地通知实现）、无支付 SDK、无社交登录 SDK；
  • 无第三方崩溃收集；
  • 无用户画像、无跨应用追踪、无数据交易。

8.1 存储地点

  • 你的设备：登录凭据、课表 / 成绩 / 考试缓存、备注、自定义课程、背景图、设置与诊断日志，全部保存在你的设备上。

  • 第三方统计：Microsoft Clarity 的数据存储于境外。

09跨境传输

我们的服务主要面向中国境内用户，核心数据（登录凭据、课表、成绩）保存在你的设备与学校系统之间， 不经过我们的境外服务器。以下场景会涉及向境外提供信息：

场景 信息类型 说明
Microsoft Clarity 使用情况记录、设备信息、IP 仅在你开启数据收集后发生；可在设置中关闭
CDN 边缘节点 IP、User-Agent、请求路径 由阿里云 ESA 就近调度，可能由境外节点响应

9.1 法律依据与保护措施

  • 统计类跨境传输以你的单独同意为依据；你拒绝或撤回同意后，我们不再产生该类传输。
  • 我们会通过加密传输（HTTPS）、最小化字段、选择具备合规资质的服务商等方式降低风险，并要求境外接收方按约定目的处理。
  • 除上述场景外，我们不会主动向境外提供你的个人信息。

9.2 你的选择

  • 不开启「允许数据收集」，即可避免 Clarity 相关的跨境传输；
  • 你可以在系统设置中限制应用的网络访问，但这会导致课表、成绩等功能不可用。

在适用法律范围内，你对自己的个人信息享有以下权利。由于我们不建立远程账号档案，大部分权利可直接在应用内行使。

关于「删除」的边界

退出登录会删除本机保存的学号、密码、账号类型与会话 Cookie，但会保留课表 / 成绩缓存、 备注、自定义课程与「上次登录学号」标记，以便你重新登录同一账号后继续使用。如果你要删除全部本地数据， 请卸载应用。

我们将在收到你的请求后 7 个工作日内回复。对于无法满足的请求（例如需要删除第三方已依法留存的数据）， 我们会说明原因。

11数据安全

11.1 我们采取的措施

  • 传输加密：与学校系统、CDN 的通信均使用 HTTPS，防止传输过程被窃听或篡改。
  • 本地隔离：数据保存在应用私有目录，受操作系统沙箱保护，其他应用无法直接读取。
  • 凭据最小化：仅保存登录所必需的学号、密码与账号类型；密码以混淆形式存储；退出登录立即删除凭据。
  • 会话隔离：更换账号时清空旧账号的会话 Cookie，避免误用他人登录态。
  • 权限最小化：只申请实现功能所必需的权限；不申请定位、通讯录、短信、摄像头、麦克风权限。
  • 日志可控：诊断日志默认关闭，最多保留 3 天，可随时清空；导出前界面会提示内容可能包含敏感信息。

11.2 你需要知道的局限

  • 密码混淆不是加密。设备被 root、被植入恶意软件或被他人物理接触时，仍存在凭据被读取的风险。
  • 学校系统的安全性由其运营方负责，我们无法保证学校系统不发生数据泄露或接口变更。
  • 互联网传输不存在绝对安全。请为设备设置锁屏密码，避免使用公共设备保存凭据。

11.3 安全事件处置

如发生或可能发生个人信息泄露、篡改、丢失，我们会立即启动调查与补救，评估影响范围， 并通过本页面、应用内公告或 QQ 群及时告知你可能受到的影响、已采取的措施与你可采取的防护建议； 依法需要向监管部门报告的，我们会按规定报告。

12未成年人保护

本应用面向南京理工大学及其他高校的在校学生，主要用户为已满 18 周岁的成年人。

  • 我们不会主动收集未成年人的个人信息，也不针对未成年人进行营销或画像。
  • 不满 14 周岁的儿童不应使用本应用；如确需使用，应由监护人陪同阅读本政策并代为操作。
  • 已满 14 周岁、不满 18 周岁的未成年人，应在监护人同意和指导下使用；监护人可代为行使本政策项下的权利。
  • 如监护人发现未成年人未经同意向我们提供了信息，可通过 QQ 反馈群联系我们，我们会尽快删除相关本地数据并停止处理。
